# Every way a search URL is built or rewritten (temporary)

Inventory for the search-intent cut-over (ISS-2291), taken 2026-10-17 from `development` at `bf24ee12`.
ISS-2371 runs **every scenario in `corpus/` through every path below** and records the output. The
refactor is done when every output is unchanged. Deleted with this directory by ISS-2377.

Only 4 call sites use `buildSearchUrl` (paths 1, 2, 5, 6). Every other path writes its own string with its
own encoding: `URLSearchParams`, `qs` (several option sets), `encodeURIComponent` templates, or the
URL replayed verbatim.

**Inputs besides the URL.** Several paths read state the URL does not carry, so the test matrix needs it
as an input too:

- **cookies** `user-pref-location`, `user-pref-coords`, `user-pref-distance` (path 22 rewrites every
  `/search` request from them)
- **search atom state** in the dialog (paths 1, 2)
- **tenant search engine** (paths 1, 2, 5, 6)
- **predict responses** (paths 2, 5, 6)
- **geocoder** (path 4)
- **CMS hrefs** (paths 3, 12, 13, 19, 20)
- **`NEXT_PUBLIC_CUSTOM_BASE_PATH` and trailing-slash settings** (path 24)
